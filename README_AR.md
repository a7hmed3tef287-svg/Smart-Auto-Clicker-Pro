# Smart Auto Clicker Pro

تطبيق Android مفتوح المصدر لتنفيذ تسلسل نقرات يحدده المستخدم يدويًا. لا يستخدم التعرف على الصور أو التقاط الشاشة.

## الميزات

- إضافة نقاط نقر متعددة بإحداثيات الشاشة بالبكسل.
- تعيين اسم وفاصل زمني بعد كل نقطة.
- تكرار القائمة عددًا محددًا من المرات أو بلا توقف عند اختيار `0`.
- حفظ النقاط وعدد التكرارات محليًا على الجهاز.
- زر إيقاف عائم قابل للسحب يظهر أثناء التشغيل.
- مهلة 3 ثوانٍ قبل أول نقرة لإتاحة الانتقال إلى التطبيق المطلوب.

## التشغيل

1. ثبّت APK من صفحة GitHub Actions، ثم افتح التطبيق.
2. أضف النقاط وأدخل X وY بالبكسل. تظهر دقة الشاشة في واجهة التطبيق.
3. اضغط **تفعيل خدمة النقر**، وابحث في إعدادات إمكانية الوصول عن **Smart Auto Clicker Pro** وفعّلها. ارجع للتطبيق.
4. اختر عدد التكرارات؛ `0` يعني التكرار المستمر.
5. اضغط **بدء**، وانتقل إلى التطبيق المستهدف خلال مهلة الثلاث ثواني. استخدم الزر العائم لإيقاف النقر فورًا.

## البناء

يتطلب البناء JDK 17 وAndroid SDK Platform 35 وGradle 8.9. يقوم GitHub Actions ببناء `app-debug.apk` تلقائيًا عند تحديث فرع `main`، ويحفظه كـ Artifact لمدة 14 يومًا.

## الصلاحيات والقيود

تستخدم خدمة إمكانية الوصول فقط لتنفيذ الإيماءات التي يحددها المستخدم. لا يطلب التطبيق إذن قراءة محتوى النوافذ، أو التقاط الشاشة، أو الاتصال بالإنترنت. لا تمنح خدمة إمكانية الوصول لتطبيق لا تثق بمصدره. قد تمنع حماية Google Play تثبيت APK محمّلًا من خارج المتجر.

هذه نسخة Debug للاختبار. يجب اختبار الإحداثيات وتوافق الجهاز قبل الاعتماد عليها. لا تعمل النقرات إذا كانت خدمة إمكانية الوصول معطلة، أو كان الهاتف مقفلًا، أو منع Android الإيماءات في التطبيق المستهدف.
