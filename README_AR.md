# Smart Auto Clicker Pro — Android Studio project

مشروع بداية منظم لتطبيق أندرويد باستخدام Kotlin وJetpack Compose.

## الموجود في هذه النسخة
- واجهة عربية لإضافة قواعد متعددة وحذفها وتعديل إعداداتها.
- إعداد لون HEX، نطاق البحث، إحداثيات الضغط، والتسامح اللوني.
- محرك بحث عن اللون داخل Bitmap.
- خدمة Accessibility لتنفيذ نقرة بعد تفعيلها يدويًا من إعدادات أندرويد.
- خدمة MediaProjection لالتقاط الشاشة بعد موافقة المستخدم.
- زر طلب إذن التقاط الشاشة وزر فتح إعدادات إمكانية الوصول.
- إيقاف/تشغيل حالة الواجهة.

## فتح المشروع
1. فك ضغط الملف.
2. افتح مجلد `SmartAutoClickerPro` من Android Studio.
3. استخدم JDK 17 وانتظر Gradle Sync.
4. اختر Build > Build APK(s).

## تنبيه مهم
هذه نسخة مصدر أولية وليست APK نهائيًا مختبرًا. لم يكتمل بعد الربط الآلي بين التقاط الشاشة ومحرك البحث ودورة تنفيذ القواعد. كما لم تنفذ ميزة Find Image أو محرر If/Else/Loops أو حفظ القواعد الدائم أو اختيار المنطقة بالسحب. يجب اختبار توافق MediaProjection مع إصدار أندرويد المستهدف قبل الاستخدام.
استخدم التطبيق فقط في التطبيقات التي تسمح بالأتمتة، ولا تستخدمه لتجاوز أنظمة الحماية أو شروط الخدمات.
